# Yash-mini-project-Batsman-Performance-Analysis-and-player-rating-system-
The project “IPL 2023 Batsman Performance Analysis Using Python” analyzes batsmen’s performance using runs, balls faced, strike rate, fours, and sixes. Python libraries such as Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn are used for data cleaning, visualization, and K-Means clustering.
